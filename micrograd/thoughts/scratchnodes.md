# micrograd follow-along

We are shown Andrej's repository on  [micrograd](https://github.com/karpathy/micrograd) and a deep dive breakdown of the auto gradient engine. Micrograd is a smaller version of the autograd method in pyTorch that allows us to find derivatives or gradients hence the name. We can apply back propogation on a loss function and move the weights and biases in a MLP to reduce the loss.
